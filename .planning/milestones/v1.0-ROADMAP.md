# Milestone v1.0: Playable Joke Mod Loop

**Status:** SHIPPED 2026-06-06 with accepted gaps
**Phases:** 1-5
**Total Plans:** 12
**Audit:** `.planning/v1.0-MILESTONE-AUDIT.md`

## Overview

v1.0 turns the Dongbei Yujie meme concept into a complete playable Fabric 1.21.11 loop: real mod identity, Daipai status/enchantment systems, Big Sweaty Foot item behavior, Dongbei Yujie entity/spawning/drop loop, resource integration, BGM behavior, hit particles, and a small Daipai HUD indicator.

The milestone audit reported gaps. The user explicitly chose to archive and accept remaining gaps as deferred work.

## Phases

### Phase 1: Project Foundation and Registries

Replaced Fabric example scaffolding with Dongbei Yujie metadata, registry anchors, client/datagen anchors, resource conventions, and public-release-safe resource policy.

### Phase 2: Daipai Core System

Implemented Daipai status effect, final level calculation, periodic aura damage, vanilla particle feedback, and Daipai enchantment levels I-V for Big Sweaty Foot.

### Phase 3: Big Sweaty Foot Item

Implemented Big Sweaty Foot as an unbreakable weapon/boots item with combat stats, armor behavior, Binding Curse handling, enchantment compatibility, wearer Daipai/fear behavior, and attacker-only hit messages.

### Phase 4: Dongbei Yujie Entity

Implemented Dongbei Yujie as a paper-standee hostile entity with spawn egg, billboard renderer, attributes, drops, Daipai integration, and night spawn registration.

### Phase 5: Linked Behavior and Resources

Integrated user-supplied resources, registered Yujie/Daipai sounds, added non-stacking client BGM, Big Sweaty Foot hit particles, Daipai trigger audio/particles, cleaned duplicate textures, and completed UAT.

### Quick Tasks After Phase 5

- Added lower-right `带派级别: X` HUD display.
- Re-enabled Dongbei Yujie targeting players while still excluding other Yujie entities.

## Accepted Gaps

The following v1.0 gaps were accepted by the user at milestone close:

- `FOOT-04`: Big Sweaty Foot hits no longer apply Daipai to targets. Current behavior is sound/chat/particle feedback only.
- `YUJI-07`: Night spawning remains vanilla-biome integrated with duplicate limiting, not an exact controlled 24-block near-player spawn attempt.
- Formal verification debt: Phases 2, 3, and 4 rely on UAT/VALIDATION/SUMMARY instead of standard `*-VERIFICATION.md`.
- Resource provenance debt: user-supplied media is integrated, but no dedicated provenance manifest exists yet.
