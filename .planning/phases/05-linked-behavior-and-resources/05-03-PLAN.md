<objective>
Implement the client-side BGM audio system. Create a MovingSoundInstance class that tracks the nearest DongbeiYujieEntity and a tick loop to play, stop, or swap BGM tracks dynamically without stacking.
</objective>

<scope>
In scope:
- Create `YujieBgmSoundInstance` inheriting from `MovingSoundInstance`.
- Add client tick event registry in `DongbeiYujieClientAudio.register()`.
- Keep the BGM playing range bounded by 64 blocks.
- Ensure the BGM stops instantly when no Yujie entities are in range, and switches immediately when a new nearest Yujie is found.

Out of scope:
- Do not implement custom server-side network packets (use purely client-side world entity scanning).
- Do not add audio fading logic.
</scope>

<tasks>
<task type="auto">
  <name>Task 1: Implement MovingSoundInstance and Tick Listener</name>
  <files>src/client/kotlin/com/columbina/yujie/client/audio/DongbeiYujieClientAudio.kt</files>
  <action>
    Define a class `YujieBgmSoundInstance` inheriting from `MovingSoundInstance` tracking a `DongbeiYujieEntity`. Set it to repeat and use `DongbeiYujieSounds.YUJIE_BGM`.
    In `DongbeiYujieClientAudio`, add client tick tracking logic. In every tick:
    1. Scan the client world for all instances of `DongbeiYujieEntity` within 64 blocks of the local player.
    2. Find the nearest one.
    3. If a nearest one is found:
       - If no sound is currently playing (or the current instance is done), play BGM tracking this entity.
       - If a sound is playing but tracking a different Yujie entity, stop the old sound and play a new one tracking the new nearest entity.
    4. If no Yujie is found, stop the playing sound instance.
  </action>
  <verify>
    <automated>./gradlew.bat compileClientKotlin</automated>
  </verify>
  <done>MovingSoundInstance and client tick tracking loop implemented in DongbeiYujieClientAudio.</done>
</task>
