# 东北雨姐趣味模组

**Dongbei Yujie Funny Mod** is a Fabric Minecraft mod that turns the Dongbei Yujie meme concept into a playable joke mod.

The project is currently in early foundation work. Phase 1 replaces the Fabric example template with the real mod identity, public metadata, registry skeletons, and resource conventions. Gameplay features such as Dongbei Yujie, Big Sweaty Foot, Daipai, voice lines, and BGM are planned for later phases.

## Planned Features

- Dongbei Yujie as a transparent PNG paper-standee entity.
- Big Sweaty Foot as both weapon and boots.
- Daipai status effect and Daipai enchantment.
- Controlled night spawning near players.
- Placeholder sound and texture hooks, followed by public-release-safe final resources.

## Build

This project targets Minecraft 1.21.11, Fabric Loader, Fabric API, Fabric Language Kotlin, Kotlin, and Java 21.

On Windows:

```powershell
./gradlew.bat build
```

The built mod jar is produced under `build/libs/`.
