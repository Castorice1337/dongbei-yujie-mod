<objective>
Register the Daipai enchantment, connect it to final-level calculation, and add public-safe vanilla particle feedback for Daipai triggers.

Purpose: Phase 2 needs the full Daipai strengthening path before Big Sweaty Foot's later weapon/boot behavior arrives.
Output: Daipai I-V enchantment available through normal enchantment flows, final-level contribution from enchanted placeholder stacks, and vanilla particle feedback.
</objective>

<scope>
In scope:
- Register `dongbeiyujie:daipai` enchantment with max level V.
- Configure it so the placeholder Big Sweaty Foot can receive it through enchantment table and enchanted book plus anvil flows.
- Make the enchantment relatively common compared with typical strong enchantments.
- Add enchantment contribution to the final-level helper.
- Add vanilla heart particles and a vanilla green star-like particle when Daipai triggers.
- Add minimal language keys for Daipai effect and enchantment if required for visible in-game names.

Out of scope:
- Do not add custom sound, texture, BGM, voice, PNG, OGG, WAV, or MP3 assets.
- Do not add Big Sweaty Foot combat, armor, curse, durability, or intimidation behavior.
- Do not add loot tables, recipes, or creative tab exposure for the placeholder item.
</scope>
