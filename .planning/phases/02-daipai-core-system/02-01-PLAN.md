<objective>
Register the Daipai status effect and establish the deterministic final-level calculation foundation for later damage and enchantment work.

Purpose: Phase 2 needs a real Buff and a single place to calculate Daipai strength before the periodic damage and enchantment plans can safely build on it.
Output: A registered Daipai effect, a minimal command-only Big Sweaty Foot placeholder item, and a reusable final-level helper.
</objective>

<scope>
In scope:
- Register a Daipai status effect under the `dongbeiyujie:daipai` identifier.
- Implement a `DaipaiStatusEffect` class that compiles and is ready for later periodic behavior.
- Register a minimal `dongbeiyujie:big_sweaty_foot` placeholder item only as a Phase 2 enchantment/level-calculation anchor.
- Implement `DaipaiLevelCalculator` or equivalent with explicit player-facing base level conversion and generic special-minimum support.
- Keep all work in `src/main` and dedicated-server-safe.

Out of scope:
- Do not implement periodic damage in this plan; Plan 02 owns the tick/damage loop.
- Do not implement Daipai enchantment registration in this plan; Plan 03 owns enchantment and anvil/table paths.
- Do not add creative tab exposure, recipes, loot tables, weapon behavior, boot armor behavior, Binding Curse behavior, hit sounds, hit messages, or intimidation behavior for Big Sweaty Foot.
- Do not reference a Dongbei Yujie entity class before Phase 4 creates it.
</scope>
